One step from live.

This portal is built and ready — it just needs to be pointed at your Supabase project. A five-minute, one-time setup:

  1. Create a free project at supabase.com and run schema.sql in the SQL Editor (full walkthrough in SETUP-GUIDE.md).
  2. In Supabase, open Settings → API and copy the Project URL and the anon public key.
  3. Open this HTML file in any text editor, find the two lines near the bottom marked SUPABASE_URL and SUPABASE_ANON_KEY, and paste your values between the quotes.
  4. Save and reload. The login screen appears — sign up, then run the one-line SQL in the guide to make your account the admin.
